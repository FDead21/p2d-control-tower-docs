# Welcome to P2D Control Tower Online

The **P2D Control Tower Online** is an integrated Tracking & Monitoring System engineered for **MSA Kargo**. It streamlines the management of import logistics, customs clearance routines, and warehouse supply tracking workflows.

## 🔄 Integrated Core Ecosystem
The platform actively synchronizes activities across five main specialized sub-systems:
* **Modul Manifest Bea & Cukai** (Customs Manifesting)
* **Modul Barang Kiriman Bea & Cukai** (Consignment Goods Processing)
* **TPS Online** (Temporary Storage Area data exchange)
* **Warehouse Management System** (WMS)
* **Transport Management System** (TMS)

## 👤 System Access Profiles
Operations are divided into key administrative roles to ensure fluid cargo transit:
1. **Admin Manifes / PLP:** Handles cargo schedule verifications and initiates customs reconciliation requests.
2. **Admin Pabean PJT:** Manages Consignment Note (CN) drafting, HS Code evaluations, and prints delivery responses like SPPB.
3. **Warehouse Operations:** Tracks warehouse entry validations (*Gate In*), cargo unloads, and outbound dispatch workflows (*Gate Out*).

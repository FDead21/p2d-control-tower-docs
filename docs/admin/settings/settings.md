# Website Settings

:::caution Admin Only
Only **Admins** can access Website Settings.
:::

![Website Settings](/img/website_settings.png)

Website Settings controls the global configuration of the platform — logo, site name, homepage banner, contact details, and social media links.

Go to **Site Settings** in the admin navigation.

---

## General Information

| Field | Notes |
|---|---|
| Website Logo | Uploaded image shown in the header/navbar |
| Website Favicon | Small icon shown in browser tabs (`.ico` or `.png`) |
| Website Name | Platform name displayed throughout the site |
| Footer Description | Short text shown in the website footer |

---

## Home Page Banner

| Field | Notes |
|---|---|
| Hero Carousel Images | Upload multiple images for the homepage slideshow — drag to reorder |
| Hero Title | Main headline on the homepage e.g. `Find Your Dream Home` |
| Hero Subtitle | Supporting text below the title e.g. `Trusted by millions of buyers & agents.` |

:::tip
Use high-resolution landscape images (1920×1080 recommended) for the hero carousel for the best visual result.
:::

---

## Contact Details

| Field | Notes |
|---|---|
| Contact Phone | Phone number shown in footer/contact section |
| Contact Email | Email address shown publicly |
| Contact Address | Office address shown in footer |

---

## Social Media

| Field | Notes |
|---|---|
| Facebook | Enter just the page handle e.g. `propertymarketplace` |
| Instagram | Instagram username |
| Twitter / X | Twitter/X username |
| YouTube | YouTube channel name |

:::info
Only enter the handle or username — the platform automatically prepends the full URL (e.g. `facebook.com/`).
:::

---

## Saving Settings

Click **Save** at the bottom of the page. Changes take effect immediately and the settings cache is cleared automatically on save.

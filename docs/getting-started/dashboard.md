# Dashboard

The dashboard is the first page you see after logging in. Its content adapts based on your role.

![Dashboard](/img/admin_dashboard.png)

## Agent Dashboard

Agents see a summary of their own activity:

| Metric | Description |
|---|---|
| **Total Properties** | Number of listings created by this agent |
| **Total Views** | Combined view count across all their listings |
| **Recent Leads** | Last 5 inquiries received on their properties |
| **Recent Properties** | Last 5 listings they created |

## Admin Dashboard

Admins see a platform-wide overview:

| Metric | Description |
|---|---|
| **Total Users** | All registered users (agents + admins) |
| **Total Properties** | All listings across the platform |
| **Total Agencies** | Number of registered agencies |
| **Draft / Pending Listings** | Properties with `DRAFT` status needing review |
| **Recent Properties** | Last 5 listings added to the platform |

:::tip
The red badge on the **Inquiries** menu item shows the count of unread (`NEW`) leads in real time — check it regularly.
:::

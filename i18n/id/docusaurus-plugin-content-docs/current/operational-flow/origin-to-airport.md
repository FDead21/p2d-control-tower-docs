# Lini Masa Operasional: Bandara Asal ke Bandara CGK

Bagian ini menjelaskan batas waktu kritis dan tanggung jawab administratif yang diperlukan saat kargo beralih dari bandara asal internasional menuju Gudang Lini-1 Bandara Soekarno-Hatta (CGK).

## ⏱️ Ringkasan Batas Waktu Utama

| Batas Waktu | Tahapan Operasional | Penanggung Jawab |
| :--- | :--- | :--- |
| **-6 Jam** | Pre-Alert | Tim Bandara Asal |
| **-1 Jam** | Fix Pre-Alert | Tim Trafik |
| **-30 Menit** | Verifikasi Admin Manifes | Admin Manifes |
| **-30 Menit** | Pengajuan Admin PLP | Admin PLP |
| **+60 Menit** | Operasional Gudang Lini-1 | Operator Gudang Lini-1 |

---

## 📋 Detail Tindakan Operasional

### 1. Pre-Alert (-6 Jam)
Kantor cabang asal internasional wajib mengirimkan manifest kargo yang berisi data lengkap berikut:
* Nomor seri M-AWB & H-AWB
* Rincian Komoditas & Kode HS (HS Number) yang sesuai
* Profil dimensi kargo, Jumlah barang (Coli), dan Berat kargo (Kilo)
* Data Invoice gabungan (dalam mata uang USD) dan NPWP Penerima (Consignee)

### 2. Fix Pre-Alert (-1 Jam)
Tim operasional Trafik melakukan verifikasi parameter kargo yang masuk untuk mengunci data, mencegah terjadinya selisih data pada proses berikutnya sebelum pesawat mendarat.

### 3. Verifikasi Admin Manifes (-30 Menit)
Admin Manifes memeriksa data status penerbangan dan mencocokkan parameter dengan catatan gudang:
* Melakukan pengecekan jadwal kedatangan pesawat (*Schedule*).
* Melakukan input data internal ke dalam modul **TPS Online**.
* Memeriksa status rekonsiliasi manifes resmi BC 1.1 dari sistem bea cukai.

### 4. Pemrosesan Admin PLP (-30 Menit)
Admin PLP mengamankan izin pemindahan transit barang:
* Berkoordinasi dengan tim Lini-1 terkait alokasi ruang kargo.
* Mengajukan formulir pemindahan lokasi penimbunan elektronik (PLP) ke Bea Cukai melalui TPS Online.
* Memantau respon sistem, mencetak dokumen persetujuan PLP, dan mencetak label pelacakan rute khusus MSA.
* Menyerahkan dokumen cetak dan label pelacakan tersebut kepada kru lapangan Lini-1.

### 5. Pemrosesan Gudang Lini-1 (+60 Menit)
Kru lapangan menjalankan prosedur penerimaan kargo dan pengeluaran terminal:
* Menerbitkan Delivery Order (DO) dan menyelesaikan pembayaran sewa penanganan gudang.
* Mencetak Surat Jalan domestik dan memasang segel pengaman Bea Cukai (*Segel Bea & Cukai*).
* Memverifikasi kesesuaian jumlah fisik barang terhadap manifes utama untuk mempersiapkan kargo ditarik menuju area Gudang TPS MSA.

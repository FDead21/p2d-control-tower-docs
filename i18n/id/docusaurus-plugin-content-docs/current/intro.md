# Selamat Datang di P2D Control Tower Online

**P2D Control Tower Online** adalah Sistem Pelacakan & Monitoring terintegrasi yang dirancang khusus untuk **MSA Kargo**. Sistem ini menyederhanakan pengelolaan logistik impor, proses kepabeanan (customs clearance), dan pelacakan inventaris gudang.

## 🔄 Ekosistem Inti Terintegrasi
Platform ini mensinkronisasikan aktivitas di lima sub-sistem utama:
* **Modul Manifest Bea & Cukai**
* **Modul Barang Kiriman Bea & Cukai**
* **TPS Online** (Pertukaran data Tempat Penimbunan Sementara)
* **Warehouse Management System** (WMS)
* **Transport Management System** (TMS)

## 👤 Profil Akses Pengguna
Operasional dibagi menjadi beberapa peran administratif utama untuk memastikan kelancaran transit kargo:
1. **Admin Manifes / PLP:** Menangani verifikasi jadwal kargo dan memulai rekonsiliasi data manifest.
2. **Admin Pabean PJT:** Mengelola pembuatan draf Consignment Note (CN), evaluasi HS Code, serta mencetak respon seperti SPPB.
3. **Operasional Gudang:** Melacak validasi masuk gudang (*Gate In*), pembongkaran kargo, dan pengiriman keluar gudang (*Gate Out*).

## 🔐 Autentikasi & Akses Masuk Sistem

Untuk masuk ke dalam ruang lingkup ekosistem P2D Control Tower Online, arahkan peramban web browser Anda menuju tautan portal resmi berikut: `http://tmsmsa.com/ptd/`

![Antarmuka Login](/img/login_screen.png)

1. **Input Identitas:** Masukkan alamat email administratif operasional Anda yang telah terdaftar pada kolom isian username.
2. **Sandi Pengaman:** Ketik kata sandi (password) pengaman akun Anda secara akurat pada kolom input password tersembunyi.
3. **Masuk Dasbor:** Aktifkan tombol toggle pengingat sesi jika menggunakan komputer pribadi yang aman, kemudian klik tombol biru **Login to Dashboard** untuk memverifikasi akun dan diarahkan langsung menuju ruang kerja dasbor Anda.
